Google AppScript Webhook

Petunjuk Google Apps Script:

  1. Buat Google Spreadsheet baru.
  2. Buka Ekstensi > Apps Script.
  3. Salin skrip Apps Script di bawah ini lalu salin URL Webhook pengembangannya.
Lihat Skrip Google Apps Script 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.timestamp, data.id, data.nama, data.kelas, data.status]);
  return ContentService.createTextOutput(JSON.stringify({"result": "success"})).setMimeType(ContentService.MimeType.JSON);
}
